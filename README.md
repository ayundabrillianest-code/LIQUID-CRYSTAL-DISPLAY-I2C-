# LIQUID CRYSTAL DISPLAY I2C

Simulasi Arduino menggunakan LCD I2C untuk menampilkan teks custom, dibuat menggunakan Wokwi.

## 🔧 Komponen

- Arduino
- LCD 16x2 I2C

## ▶️ Simulasi Wokwi

Klik link berikut untuk melihat dan menjalankan simulasi:

https://wokwi.com/projects/407636423342106625

## 📁 Files

- `sketch.ino` — kode Arduino
- `diagram.json` — rangkaian Wokwi
- `libraries.txt` — library yang digunakan
- `wokwi-project.txt` — konfigurasi project
